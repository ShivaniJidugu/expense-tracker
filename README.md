# FinTracker - Professional Expense Dashboard

An interactive, real-time personal finance manager and expense tracker dashboard built using vanilla web technologies.

## 🚀 Features
* **Live Calculations:** Real-time updates for Total Balance, Monthly Income, and Total Expenses.
* **Weekly Analytics Stream:** Dynamic line graph tracking expenditure trends across different weeks of the month.
* **Category Budget Limits Engine:** Visual threshold bars tracking allocated targets versus real-time outgoing categories.
* **Automated Savings Goals:** Smart financial corridor analyzer indicating optimization percentage tracking.

## 🛠️ Tech Stack
* HTML5
* CSS3 (Glassmorphism UI)
* JavaScript (ES6+ Core Systems)
* Chart.js (Data Visualization Pipelines)
